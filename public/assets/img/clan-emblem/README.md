# ALT-117: фон эмблемы рода

Утверждённый владельцем реалистичный фон уже лежит в комплекте бренда:

`public/assets/brand/altybayev-brand/backgrounds/clan-emblem.png`

Он используется первым. Это квадратная иллюстрация с золотой рамкой,
орнаментом и **встроенной нижней плашкой**; поверх неё не нужно рисовать
вторую рамку и вторую плашку. Жуз, название рода, ұран и исходная таңба
накладываются динамически. Не перерисовывать и не деформировать фон.

Если нужен другой вариант, можно положить замену (она используется, только
если основного файла нет):

- `approved-background.jpg`
- `approved-background.jpeg`
- `approved-background.png`
- `approved-background.webp`

в эту папку. Путь можно переопределить через `window.CLAN_EMBLEM_BG`.

Пока ни одного файла нет, рендерер показывает нейтральную каменную подложку
без пейзажа — это аварийный плейсхолдер, а не замена утверждённой
иллюстрации. Для нижней плашки в аварийном режиме рисуется своя читаемая
плашка; при наличии растра используется только встроенная.

Требования к замене: квадрат 1:1 (2048×2048+), без текста, без чужих таңба и
водяных знаков, спокойный центр под знак и место сверху/снизу под надписи.

Шрифт: сейчас Lora (шрифт сайта, поддержка казахских букв). Утверждённого
файла шрифта в комплекте бренда нет, поэтому точное семейство нужно
согласовать по образцу; это не выданная за совпадение догадка.
